# @talocode/cliploop-mcp

ClipLoop MCP server for local script, storyboard, and X export workflows plus optional hosted render jobs.

## Run

```bash
npx @talocode/cliploop-mcp
```

## Tools

- `cliploop_create_script`
- `cliploop_create_storyboard`
- `cliploop_export_x`
- `cliploop_create_render_job`
- `cliploop_get_render_job`
